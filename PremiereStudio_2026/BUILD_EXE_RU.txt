КАК ПОЛУЧИТЬ ГОТОВЫЙ EXE (без установки Node.js на вашем ПК)

1. Создайте аккаунт на https://github.com/ (если его ещё нет).
2. Нажмите New repository, задайте имя PremiereStudio и создайте Public repository.
3. Распакуйте этот архив на компьютере.
4. Откройте созданный репозиторий на GitHub, нажмите Add file -> Upload files.
5. Перетащите ВСЁ содержимое папки PremiereStudio_2026 (включая скрытую папку .github) в окно загрузки и нажмите Commit changes.
6. Откройте вкладку Actions. Дождитесь завершения задания «Build Windows EXE» (обычно несколько минут).
7. Откройте завершённый запуск workflow. Внизу страницы в Artifacts скачайте PremiereStudio-Windows-Installer.
8. Распакуйте скачанный ZIP. Внутри будет установщик PremiereStudio-Setup-1.1.0.exe.

Если GitHub спросит разрешить запуск Actions, подтвердите его.

ВАЖНО:
- Этот workflow собирает Windows-установщик на серверах GitHub Actions.
- Это не подпись издателя, поэтому Windows SmartScreen может показать предупреждение.
- Не загружайте исходники в чужие репозитории и не запускайте EXE, если не доверяете источнику.
- Сам проект пока является ранним прототипом, а не функциональным клоном Adobe Premiere Pro.
