PREMIERE STUDIO 2026 — версия 1.1
Самостоятельный видеоредактор для Windows с интерфейсом в духе современных монтажных программ.

СБОРКА УСТАНОВЩИКА EXE:
1. Установите Node.js LTS: https://nodejs.org/
2. Распакуйте архив.
3. Откройте терминал в папке PremiereStudio_2026.
4. Выполните: npm install
5. Для запуска редактора: npm start
6. Для создания установщика: npm run dist
Установщик будет в папке dist.

РЕАЛИЗОВАНО:
- Импорт видео и аудио файлов в медиабиблиотеку.
- Предпросмотр видео.
- Таймлайн с дорожками V1/V2/A1/A2.
- Добавление клипов, выбор, обрезка по началу и концу, разрезание, удаление.
- Масштабирование таймлайна.
- Сохранение и открытие проектов .pstudio.
- Экспорт последовательности клипов в MP4 через FFmpeg, 720p/1080p/4K.

ОГРАНИЧЕНИЯ ЭКСПОРТА ЭТОЙ ВЕРСИИ:
- Экспортирует видеоклипы последовательно по позиции на таймлайне.
- Экспорт пока без звука; внешние аудиодорожки не сводятся.
- Позиционирование клипов по дорожкам, переходы, титры, цветокоррекция, эффекты и GPU-ускорение пока не реализованы.
- Это рабочая ранняя версия, а не полный функциональный клон Adobe Premiere Pro.
